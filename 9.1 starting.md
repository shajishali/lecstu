# Phase 9.1 — Translation Service: Setup & Run Guide

## 1. What You Need to Define

### 1.1 Prerequisites

| Item | Required | Notes |
|------|----------|-------|
| Python 3.10+ | Yes | For `run_translate.py` |
| Node.js | Yes | For server + client |
| PostgreSQL | Yes | For LECSTU platform |
| Google Cloud account | Optional | Only for engine `google` |
| Azure account | Optional | Only for engine `azure` |

### 1.2 Environment Variables (server/.env)

| Variable | Engine | Required | Example |
|----------|--------|----------|---------|
| `PYTHON_PATH` | All | No (default: `python`) | `python` or `ai-services/translation/venv/Scripts/python.exe` |
| `GOOGLE_APPLICATION_CREDENTIALS` | google | Yes for Google | `d:\Reasearch\lecstu\keys\google-translate.json` |
| `AZURE_TRANSLATOR_KEY` | azure | Yes for Azure | `your-32-char-key` |
| `AZURE_TRANSLATOR_REGION` | azure | Yes for Azure | `eastus` |

### 1.3 File Paths

| Path | Purpose |
|------|---------|
| `ai-services/translation/` | Translation module root |
| `ai-services/translation/run_translate.py` | CLI entry (server spawns this) |
| `ai-services/translation/engines/cloud_translator.py` | Google + Azure |
| `ai-services/translation/engines/transformer_engine.py` | MarianMT |

## 2. Setup Steps

### 2.1 Install Translation Dependencies

```powershell
cd d:\Reasearch\lecstu\ai-services\translation
pip install -r requirements.txt
```

Or with a venv:

```powershell
cd d:\Reasearch\lecstu\ai-services\translation
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2.2 Google Cloud (if using engine `google`)

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Create project → Enable **Cloud Translation API**
3. Create service account → Keys → Add Key → JSON
4. Save JSON (e.g. `d:\Reasearch\lecstu\keys\google-translate.json`)
5. Add to `server/.env`:
   ```
   GOOGLE_APPLICATION_CREDENTIALS=d:\Reasearch\lecstu\keys\google-translate.json
   ```

### 2.3 Azure (if using engine `azure`)

1. Go to [portal.azure.com](https://portal.azure.com)
2. Create resource → Translator (or Cognitive Services)
3. Copy Key and Region from Keys and Endpoint
4. Add to `server/.env`:
   ```
   AZURE_TRANSLATOR_KEY=your-key
   AZURE_TRANSLATOR_REGION=eastus
   ```

### 2.4 MarianMT (engine `marian`)

No API key. First run downloads models (~300MB+).

**Steps:**

1. **Install Python dependencies** (if not already done):

   ```powershell
   cd d:\Reasearch\lecstu\ai-services\translation
   pip install -r requirements.txt
   ```

   This installs: `transformers`, `torch`, `sentencepiece`, `accelerate`.

2. **Optional: use a dedicated venv** (recommended for isolation):

   ```powershell
   cd d:\Reasearch\lecstu\ai-services\translation
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. **Point server to Python** (if using venv):

   In `server/.env`:
   ```
   PYTHON_PATH=d:\Reasearch\lecstu\ai-services\translation\.venv\Scripts\python.exe
   ```

4. **First run: download models** (~1–2 GB total):

   ```powershell
   cd d:\Reasearch\lecstu\ai-services\translation
   python run_translate.py --text "Hello" --src en --tgt ta --engine marian
   ```

   First run downloads from Hugging Face. Wait 2–5 minutes. Later runs use cached models.

5. **Models used** (all from Hugging Face):

   | Pair | Model |
   |------|-------|
   | en→ta | Helsinki-NLP/opus-mt-en-mul (prefix `>>tam<<`) |
   | ta→en | Helsinki-NLP/opus-mt-mul-en (prefix `>>tam<<`) |
   | en→si | Helsinki-NLP/opus-mt-en-inc (prefix `>>sin<<`) |
   | si→en | Helsinki-NLP/opus-mt-inc-en |
   | ta↔si | Pivot via English (two-step) |

### 2.5 mBART (engine `mbart`)

No API key. Facebook's multilingual BART. First run downloads ~1.2 GB.

**Test:**
```powershell
cd d:\Reasearch\lecstu\ai-services\translation
python run_translate.py --text "Hello" --src en --tgt ta --engine mbart
```

**Model:** `facebook/mbart-large-50-many-to-many-mmt` — supports en_XX, ta_IN, si_LK. Ta↔Si uses pivot via English.

## 3. How to Run Everything

### 3.1 Run the Full Platform (server + client)

**You need 3 things running for chat + translation to work:**

| Terminal | Command | Port |
|----------|---------|------|
| 1 | `cd d:\Reasearch\lecstu` then `npm run dev` | Client 5173, Server 5000 |
| 2 | `cd ai-services\chatbot` then `.\.venv\Scripts\Activate.ps1` then `rasa run --enable-api --cors "*"` | Rasa 5005 |
| 3 | `cd ai-services\chatbot` then `.\.venv\Scripts\Activate.ps1` then `rasa run actions` | Actions 5055 |

```powershell
cd d:\Reasearch\lecstu
npm run dev
```

- Client: http://localhost:5173  
- Server: http://localhost:5000 (handles translation API)  

### 3.2 Run Translation CLI (standalone test)

```powershell
cd d:\Reasearch\lecstu\ai-services\translation
python run_translate.py --text "Hello" --src en --tgt ta --engine google
```

Output: `{"translated_text": "...", "latency_ms": 123, "engine": "google"}`

With MarianMT:

```powershell
python run_translate.py --text "Hello" --src en --tgt ta --engine marian
```

With mBART:

```powershell
python run_translate.py --text "Hello" --src en --tgt ta --engine mbart
```

With Azure:

```powershell
python run_translate.py --text "Hello" --src en --tgt ta --engine azure
```

### 3.3 Run Translation via API (platform must be running)

1. Start platform: `npm run dev`
2. Log in at http://localhost:5173
3. Use API (e.g. Postman or curl):

```powershell
# Replace YOUR_JWT with actual token from browser cookies
curl -X POST http://localhost:5000/api/ai/translation/translate `
  -H "Content-Type: application/json" `
  -H "Cookie: access_token=YOUR_JWT" `
  -d '{"text":"Your next class is Data Structures","src":"en","tgt":"ta","engine":"google"}'
```

### 3.4 Run Translation in the UI

1. Start platform: `npm run dev`
2. Log in
3. Use **Language switcher** (navbar) → select Tamil or Sinhala
4. Open **Chat widget** → send a message → bot reply is translated
5. Open **Notifications** → titles and messages are translated
6. Open **My Timetable** → day labels (Mon, Tue, …) are translated

|-------|---------------|
| **UI (chatbot, timetable, notifications)** | Edit `client/src/hooks/useTranslation.ts` → change `engine: 'google'` to `'google'`, `'azure'`, `'marian'`, or `'mbart'` |
| **API** | Send `engine` in request body: `{"engine": "marian", ...}` |
| **CLI** | Use `--engine google` or `--engine azure` or `--engine marian` |

## 6. Troubleshooting

| Issue | Fix |
|-------|-----|
| `ModuleNotFoundError: No module named 'transformers'` | Run `pip install -r requirements.txt` in `ai-services/translation` |
| Google: "Could not authenticate" | Check `GOOGLE_APPLICATION_CREDENTIALS` path and JSON file |
| Azure: "401 Unauthorized" | Check `AZURE_TRANSLATOR_KEY` and `AZURE_TRANSLATOR_REGION` |
| MarianMT: slow first run | Models download on first use; wait ~2–5 min |
| MarianMT: `ModuleNotFoundError: transformers` | Run `pip install -r requirements.txt` in `ai-services/translation` |
| MarianMT: "Keras 3 not yet supported in Transformers" | Run `pip install tf-keras` (needed when TensorFlow/Rasa share the same Python) |
| MarianMT: CUDA out of memory | Uses CPU by default if no GPU; reduce batch size or use Google/Azure |
| Translation not showing in UI | Ensure UI language is Tamil or Sinhala (not English) |
